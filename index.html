Inspect crop ▸

AI-Assisted 360° Virtual Navigation Framework · Ongoing

  • Developing a browser-based framework that lets non-specialist staff build and publish navigable 360° virtual tours of campuses and buildings using only a smartphone and a desktop browser.
  • Built a QR-linked capture session that pairs a phone camera with the desktop workspace, so overlapping photos upload and sync in real time without a native app.
  • Implemented in-browser panorama stitching with OpenCV.js (WebAssembly), using ORB feature detection, Lowe's ratio-test matching, RANSAC homography estimation and perspective warping, so no server-side computer vision is needed.
  • Integrated Marzipano for interactive 360° rendering, where author-placed hotspots act as clickable links and as weighted edges of a scene graph (scenes as nodes).
  • Implemented Dijkstra's shortest-path routing over the scene graph, with the viewer highlighting the next hotspot at each step for turn-by-turn guidance.
  • Added a generative-AI floor-plan renderer that converts 2D plans into a top-down minimap, plus optional object-detection and LLM-based assistant endpoints for scene labels and project Q&A.
  • Built a modular full-stack back end with Node.js, Express and MongoDB, using multi-document transactions and a durable deferred-deletion queue to keep database records and uploaded files consistent.

AI-Powered Garbage Monitoring

  • Developed an AI-powered waste detection solution that analyzes CCTV footage using YOLOv11 for real-time object detection and BoT-SORT for multi-object tracking, so that people and objects are followed consistently across video frames.
  • Integrated Ollama with the Moondream VLM for semantic verification and automated description generation of detected littering incidents, helping to filter out false detections and producing clear, human-readable incident summaries.
  • The system generates real-time alerts and detailed reports for monitoring and management of improper garbage disposal, helping authorities identify incidents quickly and take timely action.
  • Applied multi-object tracking to assign persistent IDs to detected objects, enabling the system to link a discarded item to the moment and person involved in the incident rather than treating each frame in isolation.
  • Structured the pipeline as detection, tracking, VLM verification, and alert generation stages, making each component independently testable and easy to upgrade.
